Outlook Bulletproof · 4 Opções
🛡️ 100% Outlook Bulletproof: Testado e blindado contra o motor de renderização Microsoft Word (Outlook Desktop 2016-2024 / M365, Webmail Hostinger, Gmail e Apple Mail).
📌 Garantias de Compatibilidade com o Outlook (Word Engine):
  1. Sem distorção de imagens (DPI Scaling): O logotipo possui atributos HTML nativos (width="68" height="86") combinados com travas inline de max-width e max-height para que o Outlook nunca expanda a imagem.
  2. Divisor Vertical em Coluna Dedicada: Não utilizamos bordas CSS simples (que o Outlook frequentemente descarta). Criamos uma coluna de tabela dedicada de 2px com cor sólida, garantindo linha perfeita em qualquer versão do Outlook.
  3. Faixa Tricolor com mso-line-height-rule: exactly: O Outlook tem um bug clássico que estica células finas para 12px; travamos o tamanho exato de 2px via regra MSO.
  4. Fallback de Fontes Seguro: Evita a substituição automática para Times New Roman através da declaração direta de Georgia, 'Times New Roman', serif e Arial, sans-serif.
  5. Botão Retangular Bulletproof: Na Opção 3, o botão de download do Folder utiliza tabela aninhada com preenchimento em <td>, compatível com todos os clientes de email.
Estilo tradicional nobre: divisor dourado vertical em coluna blindada para o Outlook, nome, cargo, contatos e citação institucional.
