# FRIGNANI'S — WordPress Theme

Italian Excellence & International Trade.

## Structure
- `acf-json/`: ACF Pro field groups sync
- `assets/`: Images, logos, icons
- `inc/`: Theme setup and ACF field definitions
- `js/`: Frontend interactions
- `template-parts/`: Modular section components (Hero, Mission, Categories, Overview, Splash)
- `style.css`: Theme styling and metadata
